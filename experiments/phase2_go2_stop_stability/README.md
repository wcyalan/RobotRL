# 零指令偏航稳定性对照

2026-10-17：第二轮转向模型在新评估 seed=41000、42000 的左右转均达到 32/32，启停仍未通过。下一轮保持转向训练分布，仅增加零指令偏航惩罚。

## 单项干预

新增奖励项 `zero_command_yaw_l2`：当三维速度指令各分量绝对值均小于 1e-6 时，返回机身偏航角速度平方，权重 −2.0；否则为零。即额外奖励为 `−2 × yaw_rate² × zero_command_mask`，由官方奖励管理器按原有步长规则累计。非零转向、前进指令不直接施加该惩罚。

权重 −2.0 是本轮预先固定的启发式候选，不是理论最优值；不依据结果中途调权重。此项鼓励停止指令下抑制转向波动，不替代现有速度跟踪奖励，也不直接保证“连续 0.5 s”的验收要求。共享策略参数仍可能导致运动能力间接变化，因此继续评估左右转与前进。

保持 78% 普通运动、2% 站立、20% 原地转向，每 10 s 重采样；现有奖励、PPO、网络、物理随机化、终止不变。新模型从头训练 seed=0、1，各 4096×300×24=29,491,200 环境步。

对照使用第二轮 `phase2_go2_turn_coverage/run_001` 与 `run_002`，不是最初官方基线。每个新旧模型重新评估左右转、启停、前进，eval seed=40000，每项 32 环境，共 16 项、512 局；原行为验收线不变。先用256环境、24迭代短训练检查注册、配置与模型加载，再提交正式训练。

结果不支持采用 −2.0 的新增零指令偏航惩罚，也不支持直接延长本轮训练。保留第二轮转向模型作为后续参考，记录本轮负结果。即使惩罚在非零指令时为零，训练仍共享策略参数，不能保证其他行为不受影响；当前尚未证明退化的具体机制。下一步应先核对奖励实际量级和失败姿态，不直接增加惩罚强度。
