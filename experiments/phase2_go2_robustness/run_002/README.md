# 摩擦参数核验

使用训练 seed=42 的 model_299，评估 seed=20000，每项 16 局。读取运行时 Newton 材质、MuJoCo Warp geom 和 contact 参数；在第 51、501 步保存快照。实际镜像中的事件代码和求解器代码已保存。

| 条件 | 接触滑动摩擦观测 | 前进均速 | XY 误差 | 提前终止 |
|---|---|---:|---:|---:|
| 原摩擦、标称 base 质量 | 非零摩擦行为 1.0 | 0.509 m/s | 0.049 m/s | 0/16 |
| 只降低机器人摩擦至 0.3 | 非零摩擦行为 1.0 | 0.510 m/s | 0.049 m/s | 0/16 |
| 机器人与地面均设为 0.3 | 出现 0.3，缓冲中仍有 1.0 行 | 0.527 m/s | 0.059 m/s | 0/16 |

Newton 事件实现使用单一摩擦系数，忽略 dynamic_friction_range。相同 geom priority 下，MuJoCo 接触摩擦按两者逐元素最大值合成，见 [官方文档](https://mujoco.readthedocs.io/en/stable/modeling.html)；运行时所有 geom priority 均为 0。原场景地面保留 1.0，解释了只修改机器人系数时接触摩擦不降低。

结论：run_001 的 low_friction 不能作为低接触摩擦鲁棒性证据。新条件已使部分接触摩擦降到 0.3，但当前快照包含未使用的接触槽位，尚未逐接触对筛选，不宣称所有有效接触均为 0.3。

修正条件只评估了训练 seed=42；其 16 局完成且速度误差略增。进一步比较需用同一修正协议评估 seed=0、1，并记录有效接触对及其材质。
