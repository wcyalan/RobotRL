# Go2 鲁棒性初测结果

三组训练 seed（42、0、1），固定前进 0.5 m/s，评估 seed=20000，每项 16 局。共 144 局全部运行至 20 秒，无 base_contact 提前终止。模型已核验。

| 条件 | 平均前进速度 m/s | 平面速度误差 m/s | 根节点高度 m |
|---|---:|---:|---:|
| nominal | 0.517 | 0.052 | 0.242 |
| low_friction | 0.517 | 0.052 | 0.242 |
| heavy_base | 0.455 | 0.080 | 0.196 |

增加 base 质量后，速度跟踪下降且机身降低。三组模型仍维持运行，但不能把零提前终止理解为所有动作质量均合格。

低摩擦配置结果与对照接近；本轮只更改机器人材质参数，未读取求解器实际接触摩擦，因此该项暂列为待验证，不能直接得出低摩擦鲁棒性的结论。

对照固定 base 质量为标称值，与之前随机质量评估不同。此前失败案例仍保留，本轮没有为了消除该案例而修改训练策略。

后续核验：run_002 发现只改机器人摩擦时接触摩擦仍为 1.0，因此本轮 low_friction 不属于有效的低接触摩擦测试。修正设置与证据见 ../run_002/README.md。
