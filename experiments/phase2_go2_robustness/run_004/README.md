# Go2 动作延迟敏感性测试

三个训练 seed（0、1、42），评估 seed=20000，固定前进指令 0.5 m/s，标称 base 质量。模型权重不变。

| 额外动作延迟 | 平均前进速度 m/s | 平均 XY 速度误差 m/s | 平均机身高度 m | 提前终止 |
|---|---:|---:|---:|---:|
| 0 ms | 0.517 | 0.052 | 0.242 | 0/48 |
| 20 ms | 0.479 | 0.096 | 0.234 | 0/48 |
| 40 ms | 0.424 | 0.149 | 0.225 | 0/48 |

144 局全部完成 20 秒；三个 seed 均随额外延迟增加而出现跟踪误差增大、机身降低。没有提前终止不等于性能没有退化。

模型 已核验；各记录前 8 步所有环境的实际动作均与延迟队列预期一致。重置时队列填零，零动作对应默认关节目标；观测中的上一动作来自实际执行动作。

误差统计包含启动阶段，姿态/平均前进速度排除首秒。只测试额外动作延迟，未添加观测延迟；只有一个评估 seed，未直接测量打滑，不作为真机时延承受能力保证。

该结果可作为后续延迟随机化训练的对照；当前尚未修改或重训策略。
