# Go2 主线：质量与摩擦域随机化对照

## 实验范围

回到原计划的最小 DR 对照。延迟训练保留为扩展负结果，不追加训练预算。已有官方基线包含机身质量、质心和随机推扰，不能作为本实验的“无 DR”组。

本实验的“无 DR”仅指固定物理参数；训练指令、初始状态和观测噪声仍随机。只改变质量与摩擦，不修改网络、奖励、动作映射或 PPO 超参数。

| 配置 | fixed | randomized |
|---|---|---|
| base 质量倍率 | 1.0 | 均匀 0.8–1.2 |
| 机器人形状滑动摩擦 | 1.0 | 均匀 0.5–1.5 |
| 地面滑动摩擦 | 0.5 | 0.5 |
| 质心随机化 | 关闭 | 关闭 |
| 训练随机推扰 | 关闭 | 关闭 |
| 初始状态、观测噪声、随机指令 | 官方配置 | 相同官方配置 |
| 训练 seed | 0、1 | 0、1 |
| 每个模型预算 | 4096 环境 × 300 轮 × 24 步 = 29,491,200 步 | 相同 |

质量只作用于 base，不是全机器人总质量统一缩放。官方质量事件还会相应缩放惯量。随机化在 startup 执行，每个环境在训练中保持该物理参数；Newton 材料事件按形状连续采样，不是每局统一一个摩擦值。当前后端使用单个滑动摩擦系数，dynamic_friction 字段不能视为另一个独立有效参数。

地面固定 0.5 是为了使等优先级接触中的 max 合并不会遮蔽机器人 0.5–1.5 的变化。必须通过真实活动接触审计确认，不仅检查 YAML。

## 训练前固定的评估表

所有模型使用同一组条件、固定前进指令 0.5 m/s、评估 seed=30000；每条件 32 个并行环境，各取首个完整回合（上限 20 s）。关闭质心随机化和随机推扰，保留相同初始化与观测噪声。每个条件统一设置所有机器人形状的摩擦；地面仍为 0.5，范围外低摩擦条件同时降低地面以实现目标值。

| 条件 | base 质量倍率 | 接触滑动摩擦 | 用途 |
|---|---:|---:|---|
| nominal | 1.0 | 1.0 | 标称表现 |
| light_low | 0.85 | 0.6 | 范围内组合 |
| heavy_high | 1.15 | 1.4 | 范围内组合 |
| heavy_low | 1.3 | 0.3 | 范围外压力测试 |
| nominal_push | 1.0 | 1.0 | 第 5 s 一次固定扰动 |

固定扰动采用机身横向速度增量 +0.5 m/s，保持其他速度分量；它是标准化速度冲击测试，不能称为已标定力或冲量。需记录施加前后速度。若环境提前终止则记录未收到扰动，不重置后补测。

报告回报、XY 速度误差、提前终止率、回合长度，并按训练 seed 分列；32 局不能当作 32 个独立训练 seed。动力学后端非完全确定，同一 seed 不保证逐步轨迹相同。训练曲线、视频及负结果全部保留。
