# DR 定点行为诊断

本分析使用正式实验保存的逐回合指标与 env 0 轨迹；不更新训练参数、不删除异常回合。可复现脚本：`phase2_isaaclab/analysis/diagnose_mass_friction.py`。数据和源文件哈希见 `analysis.json`。

## 1. 重机身、高摩擦：平均误差由少量异常回合拉高

seed=1，fixed 为 run_002，DR 为 run_004，均为 base 质量倍率 1.15、接触摩擦 1.4、指令前进 0.5 m/s。

| 统计 | fixed | DR |
|---|---:|---:|
| 32 局平均 XY 误差 m/s | 0.04863 | 0.08544 |
| 中位数 | 0.04855 | 0.05349 |
| 最大单局误差 | 0.05644 | 0.40502 |
| 提前终止 | 0/32 | 0/32 |

DR 的 env 2、23、25 误差分别为 0.40458、0.38795、0.40502 m/s；这三局占总误差和约 43.8%。其余 29 局平均约 0.05299，仅用于定位，不用于替换完整 32 局的正式均值。0.2 m/s 是看过结果后使用的诊断阈值，不是预注册验收线。

这说明“没有 base 接触终止”没有覆盖所有跟踪失败。原始数据未记录这三个环境的完整轨迹，因此不能直接断言它们是在站着不走、侧滑还是用异常姿态运动。

原始 env 0 两组视频已导出到各自 `videos/heavy_high_env0.mp4`。这两个正常回合只能展示站姿差异，不能解释异常环境。DR env 0 的平均误差为 0.05492，明显不代表整组均值 0.08544。

## 2. 固定扰动后的短窗口误差

只使用每个模型保存的 env 0，不代表全部 32 局。第 5 秒施加一次机身横向速度增量 +0.5 m/s。

| 模型 | 未扰动：5–5.5 s 均值 | 扰动：5–5.5 s 均值 | 未扰动：5.5–7 s 均值 | 扰动：5.5–7 s 均值 |
|---|---:|---:|---:|---:|
| fixed seed=0 | 0.0487 | 0.1019 | 0.0467 | 0.0452 |
| fixed seed=1 | 0.0345 | 0.1366 | 0.0391 | 0.0406 |
| DR seed=0 | 0.0357 | 0.1211 | 0.0392 | 0.0415 |
| DR seed=1 | 0.0506 | 0.1177 | 0.0551 | 0.0520 |

单位 m/s。四个记录回合的主要误差增加集中在扰动后的前半秒，后一窗口均值接近各自未扰动对照。单回合与非完全确定性限制下，不能据小幅差值给组间恢复能力排序。

诊断中也计算了“连续 0.5 s 误差低于 0.1 m/s”的达标时间。DR seed=1 的扰动回合约 2.10 s，但未扰动对照同一时段也需约 2.26 s 才满足条件；该判据受正常步态波动影响，不能把 2.10 s 直接当作冲击造成的恢复时长。相关原始计算保留于 JSON，不用于强结论。
