- 原USD转换为44刚体、37转动关节和浮动基座的动态模型；3个碰撞体、43个可视网格，总质量32.238927 kg。
- 12组随机关节位置和基座姿态下，MuJoCo的全部刚体位置/旋转与USD关节链对照通过；质量和主惯量对照通过。
- 123维观测的顺序、质心速度坐标、原始上一动作、默认位置偏移及reset通过；P+D合力矩与限幅通过。
- 两个导出策略各4800条原始观测的动作复核通过，容差1e-5；模拟提前跌倒时能保存失败而非误记完成。共5项回归测试通过。
- 12个真实动力学回合均达到预定时长，无数值异常、无躯干接触提前终止，共260秒仿真；包含视频编码的本地总耗时约66秒。

固定镜像源码只读核对使用两个0 GPU任务：`21428713-42df-439d-9ea6-2ff4f6b7199b`、`e58bfb92-dfbd-4a3f-86f5-96dd26bc9f0f`，均成功退出。原始源码保存在本地/NAS的 `reference/`，重点核对了质心速度别名及关节P+D合力矩限幅。

## 单回合结果

每个训练seed每条件只运行1局，固定初始姿态、噪声seed=20000。静态指令20秒，启停30秒。以下“通过”仅指该单回合满足原指标，**不是原32回合、29/32的组验收**。窗口与阈值未改，接触模型和初始条件差异见代码说明。

|条件|训练seed=0|训练seed=1|
|---|---|---|
|站立|通过；平移速度0.0544 m/s|通过；平移速度0.0631 m/s|
|前进0.3 m/s|通过；平移误差0.0746 m/s|通过；平移误差0.0546 m/s|
|前进0.6 m/s|通过；平移误差0.0827 m/s|通过；平移误差0.0645 m/s|
|左转0.5 rad/s|通过；转速误差0.1359 rad/s|通过；转速误差0.1830 rad/s|
|右转−0.5 rad/s|通过；转速误差0.1369 rad/s|通过；转速误差0.1794 rad/s|
|启停|未通过连续稳定停车|未通过连续稳定停车，停车平均转速也略超限|

停车15–22秒：seed=0的平均平移/转动速度为0.0546 m/s、0.1215 rad/s；seed=1为0.0612 m/s、0.1504 rad/s（转速阈值0.15）。两者整个停车段均未达到连续1秒稳定窗口。不能据此宣称停车问题已经解决。

指标在机身坐标计算。前进指令控制机身向前速度，不固定世界系航向；尤其seed=1的前进轨迹有偏航漂移，不能把局部速度误差通过表述为世界坐标直线跟踪成功。
