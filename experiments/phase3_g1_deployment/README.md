## 复现与接口

代码入口和集群命令见 [部署说明](../../phase3/deployment/README.md)。输入float32 `[batch,123]`，输出 `[batch,37]`，不含归一化、历史堆叠或循环状态。输出是未缩放动作，环境再应用 `默认关节位置 + 0.5 × 动作`；不能直接当作关节角。

读取导出模型只需要PyTorch：

```python
policy = torch.jit.load("policy.pt", map_location="cpu").eval()
with torch.inference_mode():
    actions = policy(observations)  # observations: float32 [batch, 123]
```

实际关节顺序和控制周期记录在每个 `equivalence/summary.json`。接入其他环境时必须保持相同观测定义、关节顺序、默认姿态和动作缩放；本次独立闭环已使用这些接口。
