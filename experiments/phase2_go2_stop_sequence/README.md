# 显式启停序列训练对照

2026-10-17：用户要求继续下一轮，并持续整理失败和无用实验。本轮从有效的第二轮转向配置出发，不使用失败的 zero_command_yaw_l2 惩罚，只改变训练指令覆盖。

约20%环境（env_id % 5 == 0）按 episode 时间练习：前进0.5 m/s 5秒→停止5秒→前进5秒→停止5秒。重置从前进开始；训练器可能随机化初始 episode 长度，因此训练启动时不要求所有环境同时从第一阶段开始。提前终止可能打断序列，审计记录真实发生且不含重置的切换。

其余约80%环境每10秒随机采样：72.5%普通运动、2.5%站立、25%原地转向。这样整体保留约20%原地转向、2%随机站立、58%普通运动，另外20%为序列练习（若完整运行，前进和停止各约10%）。实际占比以审计为准，不把理论概率当实际时间占比。

指令在 CommandTerm 的更新阶段写入，位于策略观测计算之前；运行时断言 policy 观测9:12与 command manager 输出一致。训练奖励、PPO、网络、DR与终止均保持第二轮原配置，新增偏航惩罚关闭。

通过局数，第二轮转向模型→本轮启停序列模型；每项至少29/32才通过。

| seed | 左转 | 右转 | 启停 |
|---|---|---|---|
| 0 | 32→32 | 32→32 | 28→26 |
| 1 | 32→32 | 32→32 | 19→29 |

新旧模型全部512局均无非超时终止。本轮保留了左右转通过表现；seed=1启停达到验收线，但seed=0仍未通过，不能称为稳定解决启停。

前进XY误差（m/s）旧→新：seed=0为0.05665→0.05253，seed=1为0.05197→0.06614。seed=1启停改善伴随前进误差增加，应保留两项证据，不只报告有利局数。

下一步先用未参与本轮设计的新评估seed验证，尤其检查seed=1是否能重复达到29/32；当前只在eval seed=40000上验证，且训练使用了相同启停节奏，不据此声称泛化或选定最终模型。
