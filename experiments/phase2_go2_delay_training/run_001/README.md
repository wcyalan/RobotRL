# Go2 延迟随机化训练：seed=42

训练时每个环境在每局开始随机选择 0、20 或 40 ms 动作延迟，整局保持不变；重置时清空队列。4096 个环境、300 轮，共 29,491,200 步。

评估沿用 seed=20000、0.5 m/s 前进指令和标称场景；每个延迟各 16 局。

| 延迟 | 原策略速度 | 新策略速度 | 原 XY 误差 | 新 XY 误差 | 误差降低 | 原/新提前终止 |
|---|---:|---:|---:|---:|---:|---:|
| 0 ms | 0.510 | 0.391 | 0.049 | 0.136 | -177.5% | 0/16、0/16 |
| 20 ms | 0.446 | 0.374 | 0.112 | 0.164 | -46.4% | 0/16、1/16 |
| 40 ms | 0.387 | 0.341 | 0.169 | 0.200 | -18.7% | 0/16、1/16 |

速度、误差单位均为 m/s。误差降低为负表示退化。速度排除首秒，误差包含启动阶段。

本轮未取得三个条件下一致改善，不能替换原始基线。具体退化或改善应逐行比较。

短训练 72 步和正式训练 7200 步的延迟审计通过，模型与评估动作队列通过核验。agent.yaml 与原始 seed=42 基线完全相同，env.yaml 仅日志路径不同；延迟由外层包装器实现。

这是单个训练 seed 的初步干预实验，评估 seed 已用于前期诊断，不能视为独立最终验收。尚未验证其他训练 seed、未见评估 seed、传感器延迟或真机表现。
