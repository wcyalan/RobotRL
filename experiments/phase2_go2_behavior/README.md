# Go2 行为专项验收

本协议在本轮评估提交前固定，不重新训练或挑选模型。三份官方基线最终 checkpoint：seed=42、0、1；各条件 32 个并行环境，评估 seed=40000，各取首个完整回合，最长 20 s。

## 条件与指标

固定 base 质量倍率 1.0、接触滑动摩擦 1.0，关闭 COM 随机化和随机推扰；保留官方初始状态随机化、关节初始化和观测噪声。使用确定性策略，heading 模式关闭，无额外动作延迟。它是受控行为验收，不代替鲁棒性测试。

| 条件 | 指令 (vx, vy, yaw_rate) | 统计窗口 |
|---|---|---|
| 原地左转 | (0,0,+0.5) | 1–20 s |
| 原地右转 | (0,0,−0.5) | 1–20 s |
| 前进→停止→再启动→停止 | 每 5 s 切换 (0.5,0,0)、(0,0,0)、(0.5,0,0)、(0,0,0) | 前进 1–5、11–15 s；停止 6–10、16–20 s |

平移单位 m/s，角速度 rad/s。正偏航为左转；指令切换时重新计算策略观测，并断言策略输入的指令分量已更新。记录所有 32 环境的 50 Hz 速度、偏航角速度、竖直方向余弦及 active 标记，另外保存 env 0 的全姿态用于回放。

本轮使用下列工程验收线，属于项目定义，不是官方通用标准；不根据本轮结果事后放宽：

- 单局必须完整完成 20 s，无非超时终止。
- 转向：统计窗口平均平移速度 ≤0.10 m/s，平均绝对偏航速度误差 ≤0.15 rad/s。
- 前进与再启动：各窗口平均 XY 跟踪误差 ≤0.15 m/s，平均绝对偏航角速度 ≤0.15 rad/s。
- 停止：各窗口平均平移速度 ≤0.10 m/s，平均绝对偏航角速度 ≤0.15 rad/s。
- 两次停止切换后，都须在 2 s 内出现连续 0.5 s 平移速度 ≤0.10 m/s 且绝对偏航角速度 ≤0.15 rad/s。窗口必须完全位于停止阶段。
- 各统计窗口机身倾角最大值 ≤45°；不以 base 接触终止作为唯一姿态判断。
- 每个模型的每种条件至少 29/32 局满足全部对应要求，才标记该模型该条件通过；三个模型分别报告，不以合并均值掩盖失败 seed。

报告应展示实际误差、停止响应时间、通过局数、提前终止与失败编号，再结合视频解释现象。转向时机身会旋转，不能把世界系轨迹变化误认为侧滑；直接足端滑动诊断需额外接触与足端速度证据。
