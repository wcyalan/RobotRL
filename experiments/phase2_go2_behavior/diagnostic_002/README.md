## 结果

沿用原验收线重算，本次 24/32 局通过，失败环境为 5、8、15、17、21、27、30、31，均由停止响应判据失败。原测试、第一次复测、本次复测分别为 22/32、25/32、24/32，都低于 29/32；三次是同一评估 seed 的重复执行，不作为三个独立 seed 或训练改进的证据。

选取 env 8 回放：它在原测试和本次复测中第二次停止响应都为 2.58 s（不意味着逐帧相同）。本次第一次响应为 0.82 s；四个稳态窗口均通过，最大倾角均不超过 2.27°。停止后的 16–20 s 平均平移速度为 0.0381 m/s，平均绝对偏航速度为 0.0772 rad/s。

在 15.5–17 s，平移速度最大仅 0.0736 m/s，但 75 个样本中有 4 个绝对偏航速度超过 0.15 rad/s，发生于 15.68、15.80、16.28、16.66 s，最大约 0.1623 rad/s。短暂偏航越界打断连续稳定窗口，因此该案例不能描述为“无法减速”或“摔倒”。保留预先声明的严格连续窗口标准，不事后放宽；同时报告越界幅度，避免把轻微越界等同于严重失控。
