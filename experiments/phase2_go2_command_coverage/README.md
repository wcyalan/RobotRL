# Go2 指令覆盖对照

2026-10-17 建立。目的：检查增加站立、原地转向及更频繁指令切换，能否改善已有基线的转向和停止表现。不是 DR 扩展，也不更改奖励。

## 预先固定的方案

| 项目 | 官方基线 | 指令覆盖组 |
|---|---|---|
| 重采样间隔 | 10 s | 5 s |
| 指令类别 | 约 98% 原运动指令、2% 站立 | 60% 原运动指令、20% 站立、20% 原地转向 |
| 运动类 | 原有 XY 范围及 heading 模式 | 保留原有 XY 范围及 heading 模式 |
| 原地转向 | 未单独提高采样概率 | XY=0，yaw 绝对值均匀采样 0.3–0.8 rad/s，左右各 50% |
| 站立 | XYZ 速度指令为零 | XYZ 速度指令为零 |

类别在每次重采样时独立抽样，不保证每个环境每次都“走→停→走”。原地转向用直接角速度目标，运动类仍用 heading。比例与时间间隔构成一个整体干预，不能由本轮结果单独归因到某一个参数；它们是待检验的设计选择，不是已知最优值。

训练保留官方奖励、观测噪声、质量/COM/摩擦/推扰随机化、终止、执行器和 PPO 默认配置。与已有官方基线比较，不与关闭 COM/推扰的 mass-friction 实验混淆。代码在创建环境前验证除 commands 外配置完全相同，并保存 command_intervention.json、官方指令源码与实际采样计数。

## 预算与对照

- 短训练：seed=0，64 环境、12 次迭代，再加载 checkpoint 进行启停评估；只验证实现，不用短训练回报判断收益。
- 正式训练：从头训练 seed=0、1，每个 4096 环境 × 300 次迭代 × 24 步 = 29,491,200 环境步；PPO 默认参数不变。
- coverage run_001 / run_002 分别对应 seed=0 / 1；复用官方基线 run_002 / run_003 作为同 seed 对照，不覆盖或续训原模型。
- 每个新模型及对应旧模型都重新运行左转、右转、启停、固定前进四项评估，eval seed=40000，每项 32 环境。左/右转与启停保持原行为协议，固定前进使用 nominal、速度 0.5 m/s。
- 三项行为验收线沿用 phase2_go2_behavior，单项至少 29/32。报告各 seed 逐项通过局数、跟踪误差、停止响应、终止率；前进误差用于检查能力退化，不引入未经声明的新通过阈值。
- 本轮仅两个训练 seed、一个评估 seed，不声称广泛泛化；如果改善，后续再使用未用于设计的评估 seed 验证。

## 左转失败与采样诊断（2026-10-17）

复现入口：`python phase2_isaaclab/analysis/diagnose_command_coverage.py`，输出 `diagnosis.json`，保留逐局指标和源文件哈希。

三类指令实际重采样比例：seed=0 为 59.77% / 19.88% / 20.35%，seed=1 为 60.05% / 19.89% / 20.05%，与设计接近。这是采样次数比例，不是时间加权暴露比例；原审计没有保存左右转分别的计数和分模式跟踪误差，不能凭左右各半的代码设置宣称已经验证实际左右暴露完全均衡。

seed=0 新模型左转仅 env 16 提前终止，其他 31 局均运行满 20 s；这些未终止回合在第 1 秒后的平均偏航角速度仍只有 0.1203 rad/s（目标 +0.5），平均绝对误差 0.3866 rad/s。因此问题并非单次摔倒拉低均值。筛选未终止回合仅用于诊断，正式 32 局统计保持不变。

env 0 全程左转目标保持 +0.5 rad/s，1–5、5–10、10–15、15–20 s 平均实际角速度依次为 0.3501、0.1468、0.0115、0.0101 rad/s，后半段近乎停转。对应旧模型为 0.4353、0.4291、0.4931、0.4528 rad/s。新模型右转仍持续跟踪，说明左右表现明显不对称；seed=1 新模型左转平均约 0.4212 rad/s，并非所有训练 seed 都进入相同行为。

回放位于 `run_001/videos/baseline_left_env0.mp4` 与 `run_001/videos/coverage_left_env0.mp4`，均验证为 20 s、1000 帧、50 fps、960×540，元数据记录输入哈希。抽查新模型 10、15 s 以及旧模型 15 s：新模型两帧的身体朝向和腿部姿态接近，保持支撑但角速度低；旧模型该时刻仍在转向。结合完整速度记录，支持后半程近乎停转的描述；不将抽帧检查等同于全局视觉验收。渲染使用记录姿态，不重新运行物理仿真。

两个 seed 的新旧模型 `params/agent.yaml` 分别逐行完全一致，支持 PPO/网络配置未变；运行时审计也确认 commands 之外的环境配置未变。

本轮同时调整类别比例与重采样间隔，无法区分站立占比、原地转向覆盖、切换频率各自的影响。目前只能将“某个 seed 学到低运动的局部策略”作为待检验解释，不能断言根因。下一轮若继续训练，应改成单项对照：恢复 10 s 间隔及 2% 站立，仅增加原地转向覆盖（78% 普通运动、2% 站立、20% 原地转向），并增加左右采样次数与时间占比审计；保持奖励和预算不变。本轮诊断不启动该训练。
