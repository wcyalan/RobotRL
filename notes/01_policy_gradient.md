# 强化学习方法框架与策略梯度

> 参考：[知乎：PPO 算法理解——从策略梯度开始](https://zhuanlan.zhihu.com/p/614115887) §1，S&B 第 13 章。

## 1. RL 方法地图：策略梯度在哪里

按"学什么"分三大类（都不依赖环境模型，属 model-free；先学模型再规划的是 model-based，另一条线）：

| | 学什么 | 代表算法 | 策略形态 | 特点 |
|---|---|---|---|---|
| **基于值函数** | Q(s,a) 或 V(s)，贪心导出动作 | Q-Learning, SARSA, DQN | 隐式、确定性 | 样本效率高；难处理连续动作；策略不随机 |
| **基于策略** | 直接参数化 π_θ(a\|s) | REINFORCE | 显式、随机 | 天然支持随机策略与连续动作；方差大、样本效率低 |
| **Actor-Critic** | 策略头 + 价值头一起学 | A2C, PPO, SAC, DDPG | 显式（随机或确定性） | 两者折中，现代主流 |

基于值函数的路线靠递归求解 Bellman 方程（你 A2 作业写的就是这个）；基于策略的路线**跳过价值函数、直接对期望回报做梯度上升**——这就是策略梯度方法的出发点。

## 2. 目标函数与策略梯度定理

轨迹 τ = (s₀,a₀,…,s_T)，目标：

```
J(θ) = E_{τ~π_θ}[ R(τ) ] = Σ_τ P(τ;θ) R(τ)
```

**策略梯度定理**（Sutton et al. 1999，只陈述不证明）：

```
∇J(θ) = E_τ [ (Σ_t ∇log π_θ(a_t|s_t)) · R(τ) ]
```

推导只用了两步思想：

1. **log-derivative trick**：∇P = P·∇log P，把轨迹概率的梯度变成它自己分布下的期望；
2. **环境项消失**：log P(τ;θ) 中初始分布和转移概率 p(s'|s,a) 与 θ 无关，求导后只剩 `Σ_t ∇log π_θ(a_t|s_t)`。

推论：**不需要知道环境模型**（免模型的来源），只需能采样。

直觉：∇log π 是"调高该动作概率"的方向，乘上回报 = **按回报加权的加权极大似然**——好轨迹的动作概率调大，差的调小。

## 3. REINFORCE：最简单的策略梯度算法

```
1. 用 π_θ 跑完一整个 episode，得到 τ
2. 计算 G_t（从 t 往后的回报）
3. loss = −Σ_t log π_θ(a_t|s_t) · G_t     ← 交给自动微分
4. θ ← θ − α·∇loss，丢弃数据，重复
```

改进方向均来自定理：`G_t → G_t − b(s)`（减 baseline，无偏降方差）；b 取 V(s) 即 advantage `A_t = Q − V`；A 用 GAE(λ) 估计（见 [02_gae.md](02_gae.md)）。

两个固有缺陷（后两条笔记的主线）：

- **高方差**：蒙特卡洛信号抖 → critic / GAE 缓解；
- **一步走多远没保证**：步长大 overshoot，步长小 undershoot → 自然梯度 → TRPO → PPO 这条演进线解决（见 [03_ppo.md](03_ppo.md)）。

## 4. 策略的两种参数化

| 动作空间 | 策略 | 说明 |
|---|---|---|
| 离散 | **Softmax**：π(a\|s) = e^{φ(s,a)ᵀθ} / Σ e^{φ(s,a')ᵀθ} | log-grad = 观测特征 − 平均特征；好回报 + 偏离均值远 → 强更新 |
| 连续 | **高斯**：μ_θ(s) 由网络给出，σ 可学习 | log-grad = (a−μ)φ(s)/σ²；好回报时远离均值的动作触发强更新 |

实现上不手推梯度，定义 `L(a,s,r) = −log π_θ(a|s)·r` 让框架自动求导即可。

## 5. On-policy：贯穿始终的性质

策略梯度定理的期望取在 **π_θ 自己诱导的分布**上——数据必须由当前策略产生，策略一更新数据即过期。这带来两个后果：

- 样本利用率低（REINFORCE 每条轨迹只能更新一次）；
- 复用旧数据必须做修正 → 重要性采样比 π_θ/π_old，这正是 PPO 目标函数里那个 ratio 的来源。
