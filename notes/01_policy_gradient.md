# 策略梯度定理（Policy Gradient Theorem）

> Sutton et al. 1999。全部策略梯度方法（REINFORCE / Actor-Critic / TRPO / PPO）的理论基础。

## 定理

随机策略 π_θ(a|s)，目标为期望回报 J(θ)。轨迹形式：

```
∇J(θ) = E_τ~π_θ [ (Σ_t ∇log π_θ(a_t|s_t)) · R(τ) ]
```

状态分布形式（更常用）：

```
∇J(θ) ∝ Σ_s d^π(s) Σ_a Q^π(s,a) ∇_θ π_θ(a|s)
       = E_{s~d^π, a~π} [ Q^π(s,a) · ∇_θ log π_θ(a|s) ]
```

核心结论：**梯度表达式中只有策略自身的 log 梯度和回报值，不需要对环境转移模型求导**——免模型的来源。且 d^π 虽依赖 θ，但定理中不需要 ∇d^π。

## 关键引理：score function 零均值

```
E_{a~π(·|s)}[∇_θ log π_θ(a|s)] = Σ_a π(a|s)·∇π(a|s)/π(a|s)
                                = Σ_a ∇π(a|s)
                                = ∇_θ Σ_a π(a|s) = ∇_θ 1 = 0
```

概率归一化 ⇒ log-梯度按概率加权平均为零。要求 π(a|s)>0（softmax/高斯满足；确定性策略需 DPG）。此引理在证明中用三次（reward-to-go、baseline、期望形式）。

## 证明路线 1：轨迹形式（log-derivative trick）

```
J(θ) = Σ_τ P(τ;θ) R(τ)
∇J   = Σ_τ ∇P(τ;θ) R(τ) = Σ_τ P(τ;θ) ∇log P(τ;θ) R(τ)     ← ∇P = P·∇log P
```

轨迹概率展开：

```
log P(τ;θ) = log ρ₀(s₀) + Σ_t log π_θ(a_t|s_t) + Σ_t log p(s_{t+1}|s_t,a_t)
```

初始分布与转移核不含 θ，求导消失，只剩 `Σ_t ∇log π_θ(a_t|s_t)`。

**深层洞察**：θ 影响"到达哪些状态"，但该影响完全体现在"哪些 (s,a) 被采样"里，而轨迹概率中 θ 只通过 π_θ(a_t|s_t) 出现 → 不需要知道环境动力学，也不需要对状态分布求导。

**reward-to-go 精细化**：t 之前的奖励与 ∇log π(a_t|s_t) 不相关（以历史 h_t 为条件，用零均值引理证期望为 0），可删去：

```
∇J(θ) = E[ Σ_t ∇log π_θ(a_t|s_t) · G_t ]        ← REINFORCE
```

## 证明路线 2：Bellman 递归展开（S&B 第 13 章）

从 J(θ) = v^π(s₀) 出发直接求导，对乘积法则产生的"∇d^π 项"做递归吸收：

```
∇v^π(s) = Σ_a ∇π(a|s) q^π(s,a)  +  Σ_{a,s'} π(a|s) p(s'|s,a) ∇v^π(s')
          └─ g(s)：直接效应          └─ 间接效应（策略改变到达哪些状态）

∇q^π(s,a) = Σ_{s'} p(s'|s,a) ∇v^π(s')             ← p, r 与 θ 无关
```

反复代入展开成几何级数，尾项在 episodic/γ<1 下消失：

```
∇J(θ) = Σ_{k≥0} Σ_x P(s₀→_k x) g(x) = Σ_s ν^π(s) Σ_a Q^π(s,a) ∇_θ π_θ(a|s)   ∎
```

其中 ν^π(x)=Σ_k P(s₀→_k x) 为期望访问次数。**"对状态分布求导"坍缩为"按访问频次加权的逐状态直接梯度求和"**——定理真正非平凡之处。

## 两个直接推论

**baseline 无偏**：对任意不依赖动作的 b(s)：

```
E_{a~π}[∇log π(a|s) b(s)] = b(s)·0 = 0
```

→ 减 V^π(s)（换成 advantage）不改变梯度、只降方差。

**直觉**：∇log π 是"调高该动作概率"的方向，乘上动作有多好（Q/advantage）= **按回报加权的加权极大似然**。

## 从定理到算法

| 算法 | Q^π 的估计 | 备注 |
|---|---|---|
| REINFORCE | 蒙特卡洛 G_t | 无偏、高方差 |
| A2C | critic 网络的 advantage | 偏差换方差 |
| GAE(λ) | δ 序列几何加权和 | 见 [02_gae.md](02_gae.md) |
| TRPO/PPO | GAE + 重要性采样比修正 | 策略更新后旧样本过期 → on-policy 前提被破坏 |

## 备注

- 折扣情形：d^π(s) = (1−γ)Σ_t γ^t Pr(s_t=s)，结论差一个 (1−γ)⁻¹ 常数（写 ∝ 的原因）。
- 采样必须 on-policy：期望在 π_θ 自身诱导的分布上取，策略一更新样本即过期。
